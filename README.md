# Siaf YT Master AI
واجهة أولية عربية متجاوبة لتحليل روابط يوتيوب وتجهيز الفيديوهات.

## التشغيل
افتح `index.html` في المتصفح أو ارفع محتويات المجلد إلى GitHub Pages.

## حدود النسخة الحالية
- معاينة الفيديو عبر رابط يوتيوب وصورته المصغرة.
- نموذج أولي لتجهيز عناصر الفيديو.
- لا يوجد حتى الآن تحليل ذكاء اصطناعي حقيقي أو إحصاءات قناة مباشرة.

## المرحلة التالية للتفعيل الكامل
1. إنشاء مشروع Google Cloud وتفعيل YouTube Data API v3.
2. استخدام OAuth 2.0 الرسمي عند الحاجة لبيانات Analytics الخاصة.
3. إضافة خادم خلفي لحفظ المفاتيح بأمان (لا تضع API secrets داخل index.html).
4. ربط نموذج ذكاء اصطناعي لتحليل العنوان والصورة والنص واقتراح التحسينات.

هذا مشروع مستقل وغير تابع رسميًا إلى YouTube أو Google.
